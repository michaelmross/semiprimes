# Semiprimorial Triad - reproducibility bundle

This manifest defines the **minimal verification bundle** for the paper
*A Semiprimorial Triad: Prime First Hits, Semiprime First Hits, and Semiprime Recurrence*.
Files in `Fortunate/` that are not listed under **Required files** are campaign/provenance material, not dependencies of the finite claims in the paper.

## Required files

### 1. Exact `d1` verification for `1 <= n <= 100`

- `finite100_d1_witness_manifest.csv`
- `finite100_d1_certify.gp`
- `finite100_d1_verify.gp`
- `finite100_d1_certify.log`
- `finite100_d1_verify.log`

The manifest contains the 100 exact minima and the `q0^2` protection data. The certifier independently reconstructs the semiprimorials, checks minimality, proves the prime shifts, and writes ECPP certificates where needed. The verifier reconstructs the data again and validates the saved certificates.

### 2. `d2` prime-property verification for `1 <= n <= 100`

- `finite100_witness_manifest.csv`
- `finite100_certify_v2.gp`
- `finite100_verify_v2.gp`
- `finite100_certify_v2.log`
- `finite100_verify_v2.log`
- `audit_scan_v2.py`
- `scan_1_65.json`
- `scan_66_92.json`
- `scan_93_117.json`
- `audit_v2_1_65.log`
- `audit_v2_66_92.log`
- `audit_v2_93_117.log`

`audit_scan_v2.py` is the authoritative audit script for this paper. The older `audit_scan.py` is superseded and should not be cited as part of the verification bundle.

The three scan JSON files are archived inputs. The audit independently reconstructs the first semiprimes and `Q_n`, rescans every offset below each baseline scan front-runner, strips inherited and medium factors, reconstructs deferred/alive-composite sets, and checks `front_runner < q0^2` row by row. The positive manifest supplies one rigorously certifiable prime-offset semiprime witness for every `n <= 100`.

### 3. Fixed-shift `Q_n + 1` evidence through `n = 100`

- `qplus1_semiprime9_certify_v2.gp`
- `qplus1_semiprime9_verify_v2.gp`
- `qplus1_semiprime9_certify_v2.log`
- `qplus1_semiprime9_verify_v2.log`
- `qplus1_open_after_resolve.txt`

The first four semiprime hits (`n = 2, 3, 8, 9`) are explicitly factored in the paper. The two GP programs certify and independently verify the nine later hits
`15,16,19,21,23,27,29,43,65`.
`qplus1_open_after_resolve.txt` records the six deliberately unclassified cases
`52,72,74,77,80,86`.

### 4. This manifest

- `TRIAD_REPRODUCIBILITY.md`

**Total required repository files: 23.**

## Generated outputs, not required source dependencies

The GP certifiers write `.cert.gp` and `.primo` ECPP certificate files. These are regenerated by the certifier and then read by the verifier. They may be included in an archival release for convenience, but they are not independent source inputs and are not required in the minimal Git repository bundle.

Derived-state JSON files written by `audit_scan_v2.py` are likewise reproducible outputs and are optional.

- Python 3
- `gmpy2`
- `sympy`
- PARI/GP with `isprime`, `primecert`, `primecertisvalid`, and `primecertexport`

GMP-ECM is **not** required to verify the finite theorems. It was used for factor discovery in the broader campaign only.

## Core rerun commands

### Audit the `d2` scan layer

```bash
python3 audit_scan_v2.py scan_1_65.json   |& tee audit_v2_1_65.log
python3 audit_scan_v2.py scan_66_92.json  |& tee audit_v2_66_92.log
python3 audit_scan_v2.py scan_93_117.json |& tee audit_v2_93_117.log
```

### Certify and verify exact `d1` values

```bash
gp -fq -D parisize=64000000 -D parisizemax=2000000000 finite100_d1_certify.gp |& tee finite100_d1_certify.log
gp -fq -D parisize=64000000 -D parisizemax=2000000000 finite100_d1_verify.gp  |& tee finite100_d1_verify.log
```

### Certify and verify the `d2` prime-offset witnesses

```bash
gp -fq -D parisize=64000000 -D parisizemax=2000000000 finite100_certify_v2.gp |& tee finite100_certify_v2.log
gp -fq -D parisize=64000000 -D parisizemax=2000000000 finite100_verify_v2.gp  |& tee finite100_verify_v2.log
```

### Certify and verify the nine later `Q_n+1` semiprimes

```bash
gp -fq -D parisize=64000000 -D parisizemax=2000000000 qplus1_semiprime9_certify_v2.gp |& tee qplus1_semiprime9_certify_v2.log
gp -fq -D parisize=64000000 -D parisizemax=2000000000 qplus1_semiprime9_verify_v2.gp  |& tee qplus1_semiprime9_verify_v2.log
```
